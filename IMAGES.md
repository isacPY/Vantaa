# VANTA — shoe photos

All 10 photos are free Unsplash images, downloaded from `images.unsplash.com`
(no `plus.unsplash.com` — no watermarked previews used). Every file below was
downloaded with curl and **viewed** before being accepted; the descriptions are
what the image actually shows, not the search-result text. All files were
downloaded at 1200px wide (`?q=80&w=1200&auto=format&fit=crop`) and are under
300 KB, so no resizing was needed.

**Photographer names:** not available. The Unsplash photo pages could not be
opened from this machine (unsplash.com returns an Anubis bot-check to curl,
and the page fetcher blocks the unsplash.com domain), and the image-search
results did not include photographer names — so no photographer is listed
rather than guessing one. The Unsplash photo-page URL is given for each image
so the photographer can be credited from there.

**Rejected candidates (viewed, not used):** a lavender/white mesh pair for
VECTOR 02 (trim is lavender-purple, not light blue); a sage-green canvas pair
with yellow flowers stuffed inside for VERGE 10; a white/green trainer with a
bright-green sole for RIFT 06 (the shoe itself is white, not olive); a
mustard-yellow suede low-top pair, top-down with shoe trees visible, for
08-mustard; a red Nike Flyknit on a red background for 09-red (gorgeous, but
its search result gave only an Unsplash search page, no photo page, so the
red Jordan pair below was used instead for clean provenance); a close-up of a
red/black Jordan heel; a white Adidas heel close-up.
